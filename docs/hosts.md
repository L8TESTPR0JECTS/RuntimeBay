# Machine hosts

**Hosts** represents your Mac and physical or virtual machines such as Helfer. It does not enumerate Docker contexts and does not require Docker. The built-in **This Mac** entry remains available. Add remote machines with a display name, hostname/IP or SSH configuration alias, optional SSH user, and optional port. Blank user/port fields honor your SSH configuration. Editing a display name preserves the machine's stable ID.

Use **View host** to inspect the machine. The **Installed tools** view reports active executable paths and version output for Python 3, pip, Java, the Java compiler, Node.js, npm, AWS CLI, Git, Docker CLI, Maven, Gradle, pnpm, Yarn, and Go. Results distinguish **Available**, **Not found**, and **Check setup**. These are the versions visible in that account's login shell, not an exhaustive package inventory or a list of every version-manager installation. Probes do not install or upgrade software. macOS and Linux login environments are supported; remote Windows inventory is outside this version.

**Processes** shows a bounded snapshot of up to 100 process names and PIDs belonging to the logged-in user. Full command arguments and environment variables are not collected. Reinspect to update it. Process controls are available through the host's terminal; there are no automatic remote kill/restart actions.

**Terminal** / **Open terminal** creates a labeled host-specific tab inside Runtime Bay. Remote tabs execute `/usr/bin/ssh` inside the native PTY and enter the remote account's login environment. Existing SSH configuration, keys, agent, and host-key verification are used. Inspection runs in batch mode and never prompts for credentials. For password-only authentication, sign in through the host’s terminal inside Runtime Bay, keep that tab open, and retry inspection. The terminal and probes can share the authenticated [OpenSSH connection](https://man.openbsd.org/ssh_config#ControlMaster), without saving a password. Control sockets live in a private, per-app temporary directory (0700), are scoped by machine ID plus OpenSSH’s target/account hash, and are removed on app shutdown; `ControlPersist=no` avoids a detached persistent login. Unknown host keys are never accepted automatically: authenticate and verify the host in your normal Terminal first. No remote agent, deployed file, daemon port, or Docker installation is required.

**Default** is Runtime Bay's preferred machine for newly opened terminal tabs. **Make default** saves this preference in Runtime Bay only; it does not run `docker context use` or alter other applications. Explicit host terminal buttons override this choice for that tab. Project service definitions and their Start/Stop/Restart actions still execute on this Mac. Remote workflow directories, deployment, and supervised remote service definitions are not implemented yet; use the explicit SSH terminal for remote runtime commands.

The machine registry is stored atomically in `~/Library/Application Support/Runtime Bay/hosts.json`, with permissions 0600. It stores names and SSH destinations, never passwords or key contents. This file is separate from Docker's registry. Existing Docker contexts are left intact under **Containers → Docker connections**, where container operations keep their explicit Docker destination. A Docker connection and a saved machine may refer to the same physical node independently.

Inventory is cached in backend memory with a timestamp; scans are explicit, asynchronous, limited to four at once, bounded to 128 KiB of output, and time out after 40 seconds. Editing a machine invalidates and cancels its cached/in-flight scan. Removing a saved machine cancels its inventory and retains existing terminal sessions until closed. This Mac and the preferred host are protected from removal; choose another preferred host first.

Closing an SSH terminal disconnects that SSH session. Remote jobs may survive according to the remote shell, terminal hangup behavior, or service manager; Runtime Bay does not claim ownership of all processes on the remote host. Runtime Bay's local PTY supervisor cleans up the local SSH client when the tab or app closes.
